# 机械围城 · MECH SIEGE

原创科幻卡通反塔防竞速游戏。部署六种机器人，突破七种炮塔与防御设备，在 210 秒内摧毁防御中枢，刷新个人最快纪录。

## 启动与构建

需要 Node.js 20.19 或更新版本。

```sh
npm ci
npm run dev
```

浏览器打开终端输出的本地地址，默认为 `http://127.0.0.1:5173/`。

```sh
npm run typecheck
npm test
npm run validate:maps
npm run test:balance
npm run build
npm run preview
```

生产文件在 `dist/`，可使用普通静态托管。纯前端，无后端、账号或在线排行；美术文件都在工程中，运行时不请求外部图像服务。Phaser 在进入战斗时加载。

## 操作与玩法

- 从指挥舱开始下一张未通关任务，或在官方挑战中自由选择全部 20 张地图。
- 选择机器人卡牌，再点击战场任意路线部署；电能不足或冷却中不能出兵。
- `1–6` 选择机体，`Shift + 1–5` 向对应路线部署，空格或 `Esc` 暂停/继续。
- 暂停会冻结模拟、计时、资源和冷却。页面隐藏时自动暂停，回来后手动继续。
- 重装吸引火力，疾行寻找缺口；掘地机器人绕过正面设备，但会被地磁雷达探测。
- 爆破波及相邻路线；指挥机器人提供不叠加的范围伤害增益；摧毁供能站获得 25 电能。
- 冷却液洼地减速、磁轨加速带提速、检修通道防探测、工业残骸缓行、脉冲电网周期伤害。详情见指挥官手册。

## 种子、纪录与兼容

新种子示例：`MS-G1-7J2K9Q`。种子、难度、生成器版本和规则版本共同确定地图。

```text
http://127.0.0.1:5173/?seed=MS-G1-DAWN01&difficulty=easy&rules=R1
```

分享时可复制种子或完整挑战文本；其他设备需要使用实际部署域名访问，本地回环地址无法远程访问。

旧版 `ZVP-G1-…` 种子与链接继续可用，解析后与 `MS-G1-…` 指向同一内部身份。旧存档键 `gamex.records.v1`、设置键 `gamex.settings.v1`、schema 1、G1/R1、稳定单位 ID 和校验顺序保留，以兼容原版成绩、地图指纹和最佳回放。

每张地图记录挑战/通关次数、最快/最近成绩、评级及最近 30 次通关历史。最佳战斗可在个人纪录中读取和重放，支持暂停和 2 倍速，结束时验证 Tick 与终局校验值；回放不改写成绩。

本地纪录适合个人竞速，未来服务端排行必须重放验证成绩。清除站点数据会删除本地纪录；存储失败会提示，当前页面仍能继续游戏。

## 架构与美术

- `src/game/`：独立的确定性模拟、地图生成/验证、机器人策略、评级、纪录与回放。
- `src/game/config.ts`：经济、生命、伤害、速度、技能和难度参数；本次改版未调整战斗数值与评级。
- `src/render/art.ts`：统一角色资产、精灵表帧尺寸、动画状态、脚底锚点和环境选择。
- `src/render/BattleScene.ts`：Phaser 战场、移动/攻击/受击/报废动作、炮口/弹壳/电弧/冰冻/钻地/爆炸反馈。
- `src/render/RobotActor.ts`、`robotMotion.ts`、`robotPose.ts`：六种机器人的统一连续动作控制与走停、攻击、受击过渡；双足交替、疾行固定双轮、掘地履带均按实际前进距离驱动。近侧腿绘制在身体前方，远侧腿保持在后方。
- `bipedPose.ts`、`gait.ts`、`robotProfiles.ts`、`rigs.ts`、`mobileRigs.ts`：各机体独立比例、关节求解、骨轴横向加粗和素材圆轴；重装远侧持盾，爆破短腿与大靴。
- 重装前臂与盾使用独立装备图集，盾高和宽度单独配置，并固定在远侧前臂旁；机体美术验收需与参考图按同一身高对照，检查朝向、重复肩甲、衔接和装备比例。
- `src/ui/`：React 指挥舱、任务、侦察、卡牌、HUD、纪录、设置及结算。
- `public/assets/mech-siege/`：内置 imagegen 原创制作的六套机器人动作、七套设备状态、中枢、首页主视觉，以及五张新版战区全景；原始环境图保留。
- `public/assets/mech-siege/asset-prompts.json`：实际生成提示词与所用模式；`dimensions.json` 记录原始尺寸和体积。透明像素保留在 PNG 中，React 与 Phaser 共用同一资源。

模拟使用 30 Tick/秒、整数坐标/生命值和固定处理顺序，画面帧率不决定战斗结果。渲染只读取快照和事件。修改已发布的规则或生成逻辑必须增加版本并保留旧实现。

## 验证与边界

测试覆盖战斗、资源、兵种技能、地形、帧率、48 个随机地图组合、20 张官方任务和三类策略。`src/game/fixtures/legacy-r1.json` 固定改版前的真实地图、存档与三段回放；兼容测试禁止重新生成该基准。

美术资产测试检查全部精灵表尺寸、透明通道、动画帧索引和环境文件。具体浏览器验收和剩余未验证项见 `.agentdocs/index.md` 指向的改版文档。

开发服务可打开 `http://127.0.0.1:5173/walk-lab.html`，检查四种双足机体的完整循环、逐段姿态、慢放、冷冻、停步、攻击、受击与暂停；可选择单个机体放大和显示关节。`leg-pixels.test.ts` 额外验证真实透明轮廓没有腿段残片穿地、支撑脚悬空或邻格串片。该页直接复用战场动画，不写入存档，不包含在默认生产构建入口中。

桌面优先，提供窄窗口布局；完整移动真机、多浏览器矩阵、长时间性能和真人数值平衡仍需后续专项验证。PNG 原始素材体积较大，首次进入游戏需要加载素材；生产构建中的 Phaser 依赖仍有单块体积提示。
