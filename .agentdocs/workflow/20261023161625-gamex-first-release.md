# GameX 首版完整实现（会话-3 至会话-11）

## 背景与目标

从空工作区实现完整可玩的原创反塔防竞速游戏。按用户附件的六个阶段推进，交付本地工程，采用明亮原创卡通；暂停冻结战斗、尸能、冷却和计时，暂停期间不能出兵。

初始分支为无提交的 `main`；本次开发位于 `codex/gamex-zombie-time-attack`。尚未创建 Git 提交。会话编号、本文档和当前分支共同定位本次任务，后续不要凭聊天记忆回滚。

## 约束与原则

- 纯前端，TypeScript、React、Phaser 3、Vite、Vitest、localStorage；无账号、后端与在线排行。
- 30 Tick/秒，地图和模拟可脱离渲染运行；植物阵地固定，无战略 AI。
- SVG 角色、战场装饰、动画和合成音效由项目代码原创生成，不使用受保护游戏资产。
- 相同任务共用本文档；AGENTS.md 记录长期架构和检索规范，不记录临时问题。

## 关键实现与决策

- 坐标和生命值使用整数，资源使用累计整数差分恢复，避免逐帧舍入漂移。命令绑定模拟 Tick 和递增顺序，仅记录成功部署。
- 植物固定选择同路线左侧最近目标，相同距离按 ID 排序；僵尸攻击前方最近的植物，抵达核心后攻击核心。
- 地道单位到 7.2 格后出土；探测菌可提前迫使其现身，隧道格可防探测。阳光花摧毁后奖励 25 尸能。
- 指挥官范围增益不叠加；铁甲仅减少普通弹丸伤害；爆破可波及相邻路线。地刺每四秒激活一秒，每周期对进入者伤害一次。
- 生成器先覆盖全部路线，再分配剩余预算，避免早期路线耗光预算。地图生成时运行基础机器人，失败后继续有上限的确定性候选选择。
- 官方地图种子自动解析对应风格，分享 URL 与官方入口生成同一地图。地图身份含种子、G1、R1、难度。
- 评级由三类机器人实测标定：SS/S/A/B 分别取最佳机器人基准的 80%/95%/115%/160%，其余通关为 C。随机地图单独跑机器人标定，不共用统一阈值。
- localStorage 采用 schema 1，按地图身份保存最近 30 次通关历史及最佳回放；读取损坏、空间不足或禁用存储时降级内存并提示。
- 回放包含兵种配置、命令和最终校验值；不会增加挑战次数或覆盖成绩。未来在线成绩必须通过服务端重放验证。
- Phaser 按进入战斗时加载；构建仍有 Phaser 单块大于 500 kB 的提示（gzip 约 332 kB），属于当前依赖体积限制。
- Phaser SVG 加载器需要 Base64 数据地址，曾导致加载卡住，已在浏览器定位并修复。

## 剩余风险与未验证项

- 机器人保证基础可通关与战术差异，不证明最优解或绝对平衡；评级和数值需要更多真人试玩。
- 未完成多个浏览器/设备的系统兼容矩阵和移动端真机触控专项验收。
- 已实现 visibilitychange 后台自动暂停，但当前内嵌浏览器测试工具切换标签未产生真实隐藏状态，因此该浏览器行为仍需人工专项验证。
- 尚未进行长时间压力测试和内存性能剖析。切换与重开会销毁旧 Phaser 实例，相关浏览器链路已运行。
- 无云端备份；清除站点数据会丢失本地成绩。没有公网部署，本地链接不能直接供其他设备访问。
