# 《机械围城》科幻卡通全面改版（会话-15 起）

## 背景与目标

将原版整体改为未来机器人攻城题材。采用已确认的深蓝指挥舱、明亮工业战场、活泼拟人卡通机器人，兼容旧纪录与回放。保留出兵、种子、竞速和自动战斗机制，不调整战斗数值与评级。

本任务使用分支 `codex/gamex-zombie-time-attack`，与首版一致。当前仓库尚无提交，本任务未创建 Git 提交，精确变更应在首次提交时一并纳入版本管理。

## 约束与决策

- 展示、输入示例和分享统一使用 `MS-G1-…`；解析后规范化回 `ZVP-G1-…`，保留原地图身份。
- 沿用 `gamex.records.v1`、`gamex.settings.v1`、schema 1、G1/R1、稳定单位 ID、序列化字段及校验顺序。
- `src/game/fixtures/legacy-r1.json` 在实施前固定，保存原版 20 张地图、三段真实回放及存档。不得为了适配新实现重新生成。
- React 头像与 Phaser 战场共用 PNG 和资产清单。表现层只读取模拟快照与事件。
- 使用内置 imagegen 原创生成美术，不接入图像 API，不使用外部游戏资产。声音继续采用程序合成。
- 历史变更文档保留原始题材，不批量改写历史记录。

## 主要变更

### 品牌与内容

- 游戏名统一为《机械围城》，资源为电能，目标为防御中枢。
- 六种机器人：先锋、重装、疾行、掘地、爆破、指挥。
- 七种设备：动能炮塔、装甲屏障、冷冻发射器、供能站、感应地雷、地磁雷达、等离子重炮。
- 五类地形改为冷却液洼地、磁轨加速带、检修通道、工业残骸和脉冲电网。
- 20 张官方地图按废土前哨、合金工厂、地下能源站、轨道港区、主控堡垒重新命名。布局、难度、评级阈值和内部种子保持不变。
- 更新标题、图标、教程、说明、提示、分享内容和 README。

### 原创美术与动画

- `public/assets/mech-siege/` 保存 20 份正式 PNG：六套机器人、七套设备、防御中枢、五个环境和首页主视觉。
- 六套机器人采用四列两行，每套八帧；设备与中枢为两列两行，每套四帧，共 80 帧。
- `asset-prompts.json` 记录实际提示词及内置模式；`dimensions.json` 记录实际尺寸和体积。
- 逐帧检查后对六套机器人的攻击和受击帧做局部修整，缩短前伸装备并移除跨格碎片，保留其余帧和原始画风。实际修整提示词记录在各任务的 `edits` 字段。
- `src/render/art.ts` 统一纹理路径、帧尺寸、动画索引、显示大小和脚底锚点。增加展示用 RobotType / DefenseType 与 ROBOTS / DEFENSES，持久化 ID 沿用旧版。
- 战场保留五路十二列，使用独立中枢、部署区、主题环境与地形标记。
- 接入移动、攻击、受击和报废状态；增加炮口闪光、弹壳、弹弧、装甲火花、冰冻、钻地尘、技能光环和中枢爆炸。加载失败反馈到界面提示。

### 全页面 UI

- 深蓝指挥舱、青色选中状态、橙色主操作，统一面板、按钮、卡片、标签和弹窗。
- 首页采用原创机器人主视觉、继续作战入口、战役进度和纪录摘要。
- 官方地图使用战区任务面板，随机地图使用带实际阵地预览的侦察控制台。
- 战斗 HUD 集中显示时间、电能和中枢生命；底部机器人卡牌具备冷却遮罩、选中状态和键盘提示。
- 纪录、回放、暂停、结算、设置与手册采用同一视觉规范。
- 1280×720 下压缩标题区并限制战场高度，保证五条路线和六张卡牌可见。窄窗口折叠侧栏并重排内容，保留焦点及减少动态效果设置。
